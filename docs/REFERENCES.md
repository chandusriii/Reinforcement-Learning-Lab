# Learning and Project References

This page records the source materials that informed the notes and project direction.

## Course materials supplied for this repository

- **Deep_Learning-42 3.pdf** — Reinforcement Learning introduction, agent/environment components, MDP, grid-world example, and exploration–exploitation.
- **Reinforcement_Learning part2.pdf** — Dynamic Programming, Monte Carlo methods, Temporal-Difference learning, SARSA, Q-Learning, Cliff Walking, Gymnasium interaction, and implementation notes.
- **FlappyBird_DQN_Code.pdf** — assigned Flappy Bird DQN code repository and note about generating a `runs` folder during execution.
- **Reinforcement Learning _Assignment Project.pdf** — Mario-playing agent assignment using Double DQN.

## Project implementation references

- **Flappy Bird assigned implementation:** [RL_DQN](https://github.com/shradha-khapra/RL_DQN). Used as the starting implementation for the Flappy Bird coursework project. Preserve its license and notices when using or redistributing code.
- **Mario Double DQN tutorial:** [PyTorch — Train a Mario-playing RL Agent](https://docs.pytorch.org/tutorials/intermediate/mario_rl_tutorial.html). Linked by the supplied assignment.
- **Flappy Bird Gymnasium environment:** [flappy-bird-gymnasium on PyPI](https://pypi.org/project/flappy-bird-gymnasium/).

## How references are used

The course PDFs are the basis for the learning notes. The project links guide implementation work. Explanatory additions are included to make the material easier to follow, while algorithm-specific distinctions (such as standard DQN vs. Double DQN) are called out explicitly.
